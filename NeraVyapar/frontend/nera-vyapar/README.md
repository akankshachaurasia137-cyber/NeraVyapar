# Nera Vyapar frontend

React + Vite + Tailwind CSS + React Router + Lucide icons.

    npm install
    npm run dev      # http://localhost:5173
    npm run build

- `/driver`: driver dashboard, find loads, load details (30-minute hold), my truck, active trip, bookings, earnings, notifications, profile
- `/trader`: trader dashboard, post load, my loads, find trucks, bookings, tracking, payments, profile
- Mock data lives in `src/data/` (swap for API calls later). Translations (English / ಕನ್ನಡ / हिन्दी) are in `src/i18n/translations.js`.
- Logo files are in `public/`; `logo-wordmark.png` is used in the sidebar.
